# 01 — 系統概述與需求規格

> 個股網路溫度系統（Stock Heat）— 設計文件 1/7
> 版本：v0.1 ｜ 最後更新：2026-06-29

## 1. 系統願景

個股網路溫度系統（以下簡稱「本系統」）的目標，是把分散在新聞、論壇、社群、搜尋趨勢上的「網路討論熱度與情緒」量化成每檔股票每天（與盤中）的**網路溫度分數（Heat Score, 0–100）**，協助使用者：

- 即時掌握哪些個股正在被「炒話題」，及其情緒是偏多還是偏空。
- 找出「溫度異常升溫」的個股（潛在事件、題材發酵）。
- 觀察溫度與股價、成交量之間的領先／落後關係。

本系統**不提供投資建議**，僅提供資訊指標。所有輸出皆附資料來源與計算依據。

## 2. 名詞定義

| 名詞 | 定義 |
|------|------|
| 網路溫度（Heat Score） | 綜合「討論聲量」「情緒強度」「來源權重」「時間衰減」後得到的 0–100 分數 |
| 聲量（Volume） | 單位時間內提及該個股的內容則數（去重後） |
| 情緒分數（Sentiment） | 內容文本的偏多／偏空傾向，範圍 -1（極空）~ +1（極多） |
| 來源權重（Source Weight） | 不同資料來源的可信度／影響力加權 |
| 升溫率（Heat Velocity） | 溫度相對前一週期的變化率，用於偵測異常 |
| 標的（Ticker） | 一檔個股，以證券代號標示（例：2330 台積電） |

## 3. 目標使用者與情境

1. **散戶／個人投資人**：每天開盤前看「今日升溫榜」，盤中看自選股溫度。
2. **內容／分析人員**：回溯某事件期間個股溫度曲線，做事件影響分析。
3. **量化研究者**：透過 API 取得歷史溫度時序，作為選股因子之一。

## 4. 範圍（Scope）

### 4.1 第一階段（MVP，本專案重點）
- 鎖定**台股上市櫃**個股（約 1,800 檔）。
- 資料來源：**財經新聞**（第一個落地模組）、PTT Stock 板、主要財經論壇。
- 計算每日溫度分數與情緒分數，提供升溫榜與個股詳情。
- 提供 REST API 與基礎儀表板。

### 4.2 第二階段（後續）
- 盤中即時溫度（分鐘級）。
- 擴充社群來源（X/Threads、Dcard、YouTube 留言）。
- 溫度 × 股價回測框架、警示通知（Webhook/LINE）。

### 4.3 不在範圍內
- 不做下單、不做投資組合管理。
- 不爬取需登入或違反服務條款的內容；遵守各來源 robots 與授權規範。

## 5. 功能需求（FR）

| 編號 | 功能 | 優先級 |
|------|------|--------|
| FR-1 | 定時擷取財經新聞並關聯到個股 | P0 |
| FR-2 | 對每則內容做中文斷詞、個股辨識、情緒分析 | P0 |
| FR-3 | 計算每檔個股每日溫度分數與情緒分數 | P0 |
| FR-4 | 提供「今日升溫榜 / 降溫榜」 | P0 |
| FR-5 | 提供個股溫度歷史時序查詢 API | P0 |
| FR-6 | 偵測溫度異常升溫並標記事件 | P1 |
| FR-7 | 儀表板：榜單、個股詳情、溫度 × 股價疊圖 | P1 |
| FR-8 | 自選股與溫度警示通知 | P2 |

## 6. 非功能需求（NFR）

- **資料新鮮度**：新聞自發布到入庫 ≤ 15 分鐘（盤中來源 ≤ 5 分鐘）。
- **可擴充性**：新增一個資料來源不需改動核心計算邏輯（plugin 化擷取器）。
- **可重算性**：演算法參數調整後，可對歷史原始資料重新計算溫度（保留 raw 與 derived 分層）。
- **可觀測性**：每個擷取器有成功率、延遲、抓取量指標。
- **合規**：尊重來源 robots.txt 與 rate limit；儲存原文僅供內部計算，對外只輸出聚合結果與來源連結。
- **可用性**：API 月可用度目標 99%。

## 7. 成功指標（KPI）

- 新聞→個股關聯正確率 ≥ 90%（人工抽樣評估）。
- 情緒分類在標註集上的 Macro-F1 ≥ 0.75。
- 「升溫榜」前 10 名與當日實際大量成交／異動個股的重疊度（觀察性指標）。

## 8. 主要風險與對策

| 風險 | 對策 |
|------|------|
| 來源改版／反爬導致斷料 | 擷取器 plugin 化 + 每來源健康度告警 + 多來源冗餘 |
| 中文金融情緒分析準確度不足 | 先用規則+詞典打底，逐步導入領域模型，保留可重算 |
| 個股簡稱／同名造成誤關聯 | 建立股票別名詞典 + 上下文消歧 + 信心分數門檻 |
| 法遵與版權 | 僅存必要片段、對外標來源、遵守授權 |
